# Financisto

## DEPRECATED ##
Check https://github.com/tiberiusteng/financisto1-holo for better finacisto fork.

## About

This is a fork-of-a-fork of my long time favorite personal finance
tracker app. My current main goal is to deal with deprecated code to
make the app reasonably future proof.

## Restore from the original financisto

The backup file is compatible with this Financisto+ version. The
restore function can now also open files from Google Drive (if the
Drive app is installed) and possibly other cloud storage apps.

## Known issues
* Google Drive and Dropbox backup functions are disabled for now.
* SMS function is suspended because Google Store does not grant SMS
  permission to this application.
* Tab icons on the main screen are not visible now due to UI
  refactoring in progress.

## Features

- Multiple accounts, multiple currencies 
- Home currency and exchange rates
- Transfers with downloadable rates
- Scheduled & recurring transactions
- Split transactions
- Hierarchical categories with custom attributes
- Recurring budgets
- Projects and payees
- Filtering and reporting
- Cloud backup (Dropbox, Google Drive)
- Automatic daily backups
- QIF/CSV import/export
